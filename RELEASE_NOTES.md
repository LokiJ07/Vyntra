# Vyntra v0.2.1

- Added a new **Videos** tab with in-app YouTube mobile search (WebView), search query input, WebView navigation, and selected video URL detection.
- Added **Copy Link** and **Use Link** for actual video links, not a title or attribution.
- Prominent reminder: ordinary video page links cannot be downloaded via the direct-audio-file download manager; no YouTube-to-MP3 conversion is included.
- Existing Music search, authorized downloads, signing identity, and app data preserved.
- **Testing status**: static checks and URL tests locally; Gradle and device testing pending.
